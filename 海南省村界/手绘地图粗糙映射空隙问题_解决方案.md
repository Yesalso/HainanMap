# 手绘地图粗糙 → 映射回 SHP 后大量空隙：成因与解决方案

> 输入案例：`三亚乡镇2002_123.shp`（手绘 2002 反向映射初版，54 片段）
> 修复结果：`三亚乡镇2002_123_fixed.shp`（9 乡镇）
> QA 报告：`三亚乡镇2002_123_fixed_QA报告.md`
> 工具：`Sanya/fix_slivers.py`、`Sanya/reverse_sanya_2002.py`、`town/ReverseCounty2002.py`、`town/wenchang/reverse_by_color.py`
> 经验来源：`town/2002海口转换总结.txt`

---

## 1. 问题现象（以三亚 QA 报告为证）

修复前诊断（`三亚乡镇2002_123.shp`）：

```
n: 54                 # 被拆成 54 个片段
gap_count: 13         # 13 处细小空隙
gap_area: 10600.65 m² # 空隙总面积
gap_sources: {'closing': 13}   # 空隙全部由形态学闭运算产生
close_pairs: 31       # 31 对要素几乎贴在一起但没接上
min_pair_distance: 8.42 m      # 最近的一对只差 8.42 m 却仍是断的
thin_parts: 13 / thin_area: 29875.09 m²   # 13 条细长碎片
```

争议区明细（29 行）显示：空隙宽度 0.6 ~ 44.3 m，全部是 `thin-gap/orig-owner`，
绝大多数归到 `460200002`（田独镇），原属 `460200101` / `460200102`。
也就是说：**相邻乡镇之间普遍存在 10~45 m 量级的细缝，且彼此犬牙交错。**

修复后：

```
features: 9
domain_missing_m2: 55.551   # 残余空隙 55.6 m²（= 5191 个纳米级碎片）
domain_excess_m2: 0.018     # 残余重叠 0.018 m²
interior_rings: 527         # 出现 527 个内部孔洞（需警惕！）
sum_minus_union_m2: 1.933
internal_symdiff_km2: 5.052572   # 2002/2007 真实历史差异
```

结论：修复把 10600 m² 的缝隙压到 55.6 m²（残余全是肉眼不可见的布尔伪影），
但代价是产生了 527 个内部孔洞 —— 说明"缝隙"若不彻底归并，就会转化成"孔洞"。

## 2. 根因分析

空隙不是单一原因，而是 6 类误差叠加。按"产生阶段"归类：

| # | 阶段 | 成因 | 表现 |
|---|---|---|---|
| 1 | 矢量化 | **逐区域独立取轮廓**：每个区域单独洪泛 + `findContours`，共享边界被描两次，像素取整方向不同 | 相邻要素间 1px 缝/叠 |
| 2 | 栅格化 | **量化台阶**：30 m/px，轮廓顶点落在像素中心，半像素偏移 | 锯齿 + 半像素缝 |
| 3 | 手绘 | **线条本身不闭合**：断笔、出头/欠头、斜向透缝 | 闭运算前成片漏缝 |
| 4 | 形态学 | **闭运算副作用**：`(U⊕r)⊖r` 在细腰/凹角处制造新缝 | `gap_sources={'closing':13}` |
| 5 | 求交 | **与权威外轮廓求交**后边缘产生细碎条带 | 沿海/边界处碎片 |
| 6 | 布尔运算 | **浮点伪影**：GEOS 求差产生纳米级假孔洞 | `interior_rings:527` |

**核心矛盾**：只要"每个单元各自成面"，共享边界就不可能严格重合；
必须改成"**先划定整个区域，再切分**"，从机制上消灭空隙。

## 3. 解决方案（分 7 层，从预防到收尾）

### 第 0 层（最关键）：用"严格分区"取代"独立取面"

三种可选范式，按适用场景选择：

**方案 A —— 从权威 SHP 做集合差切分（首选，零空隙）**
> 实现：`town/wenchang/reverse_by_color.py`

前提：手绘图是"在现行 SHP 上改的"，改动区已知（如彩色块）。
做法：
```
children = 彩色块轮廓 ∩ 所属现行乡镇      # 只裁不并
remain   = 现行乡镇 − union(children)     # 差集
```
数学上恒有 `union(remain, children) == 原乡镇`，所以：
- 无缝隙（remain 吸收了一切边界残差）
- 无重叠（children 互不相交且 ⊆ 乡镇）
- 面积严格守恒

实测（文昌）：27 单元、面积 2457.274 km² 完全守恒、重叠 0、黑线贴合 ≤100 m 达 100%。
**这是"手绘图粗糙"最省事的解法：粗糙的边界只影响被拆分的那个乡镇内部，
绝不产生跨要素缝隙。**

**方案 B —— 栅格域"无缝无叠唯一归属"（完全重绘时用）**
> 实现：`town/ReverseCounty2002.py:218-256`

```
线网膨胀 1px 成"墙" → 白色区 8 连通洪泛 = 各单元种子
→ 对全图做欧氏距离变换(EDT)，把每个墙/缝像素归给"最近种子"
```
保证**全域覆盖、唯一归属**，从栅格层面就没有无主像素。

**方案 C —— 平面图分区（polygonize）**
把所有边界线合成平面图，`polygonize` 出全部面，再按面归属。
共享边界天然唯一，无重复描边。

### 第 1 层：配准（消半像素偏移）
- 模板匹配定偏移（海口 `(0,310)`；文昌 `(0,0)`）。
- 像素中心约定 `x=minx+(i+0.5)*sx`；反向 `col=(x-minx)/sx-0.5`。
- 轮廓顶点**吸附到线网中心像素**（半径 ≤2px）消半像素偏移。
- 形态学**闭运算**桥接断笔、**线网膨胀 1px** 堵对角透缝、**文字掩膜**剔除地名。

### 第 2 层：缝隙检测（三通道，`find_gaps` `fix_slivers.py:387`）
- 通道1 `polygonize`：平面图里无人覆盖的封闭面；
- 通道2 闭运算：`(U⊕r)⊖r − U`，捕捉**通向外部**的开口细缝；
- 通道3 域约束：`domain − U`，参考域内本层缺失部分。
- 过滤：宽度 ≤ `max_gap_width`、面积 ≤ `max_gap_width²×400`、
  **至少接触 2 个要素**（接触 1 个 = 海岸凹湾、0 个 = 开阔海域，都不许填）。

### 第 3 层：缝隙归属（Eliminate 等价，`assign_gaps` / `resolve_partition`）
- `assign_gaps` 优先级：**同码优先 → 公共边界最长 → 接触面积最大**（STRtree 加速）。
- `resolve_partition` 争议区回退链：
  **原始图层归属 `orig-owner` → 权威参考 `ref-owner` → 最长公共边界 `longest-border` → 放弃并报告**。
- **关键洞见**：重叠与空洞的正确答案是同一个 ——
  "该地块在**原始图层**里属于谁，配准后就还归谁"。这一条既消缝消叠，又保住拓扑语义。

### 第 4 层：配准式修复（`conflate_to_reference` `fix_slivers.py:889`）
```
A_new = R_A ∪ opening(A \ R_A, r)  \  opening(R_A \ A, r)
```
- 与权威边界差异**厚度 < 2r** → 判为 1px 级配准噪声，**抹平**（消缝、消叠）；
- 差异**厚度 > 2r** → 判为**真实手绘改动，保留**。
- 这一步是"既贴权威、又保真"的核心；`r` 由分辨率定（见参数表）。

### 第 5 层：邻居顶点吸附（`snap_neighbors`，仅 topo 模式）
- 把相距 `< tol` 的邻居顶点互相吸附；先把参考线 `segmentize(tol/2)` 加密。
- **三重守卫**（防 make_valid 炸面）：合法性、面积变化率 ≤25%、部件数增幅 ≤3 倍。

### 第 6 层：收尾（消纳米伪影）
- `drop_micro_holes`：删面积 < `min_hole_area` 的孔洞（消 `interior_rings` 爆炸）；
- `precision_normalize(grid)`：固定精度网格消浮点伪缝；
- `remove_overlaps`：顺序占用，面积大者优先，保证互斥；
- 微空洞回填：≥`min_area` 的按最长边界归属，更小的计入残余并报告。

## 4. 参数建议表（随像素分辨率缩放）

| 参数 | 含义 | 建议取值 | 依据 |
|---|---|---|---|
| `snap_tol` | 顶点吸附/邻居判定 | ≈ 1 px（30 m/px→30 m；20 m/px→20 m） | 一个像素 |
| `max_gap_width` | 细缝最大宽度 | 2 × snap_tol（30 m/px→60 m） | 跨 2 像素内算缝 |
| `conflate_tol (2r)` | 配准噪声厚度阈值 | ≈ 3 px（30 m/px→90 m；20 m/px→60 m） | `_tune_conflate.py` 扫描 30~2000 m 选 90 m |
| `min_hole_area` | 微孔洞阈值 | 1 m² | 远小于真实湖泊/飞地 |
| `min_area` | 争议碎片最小面积 | 1 m² | 纳米伪影不处理 |
| `grid` | 精度归一网格 | 0.001 m | 消浮点噪声 |
| `area_cap` | 细缝面积上限 | `max_gap_width² × 400` | 防把大块缺失当细缝填 |

## 5. 标准流程与命令

```powershell
# ① 反向映射（完全重绘用方案B；在现行图上改用方案A）
python ReverseCounty2002.py --shp 海南村界.shp --code-field XZQDM --name-field XZQMC `
    --county 460200 --img Sanya2002.png --out 三亚乡镇2002_123

# ② 配准式修复（挂权威参考，消缝消叠保真）
python fix_slivers.py --input 三亚乡镇2002_123.shp `
    --ref ../../海南村界.shp --ref-key 乡镇码 --key 乡镇码 `
    --mode snap-ref --conflate-tol 90 --dissolve-by 乡镇码

# ③ 合并回全岛 + 校验出图
python ApplyCounty2002.py --hainan Hainan2002/Hainan_town.shp `
    --county 三亚乡镇2002_123_fixed.shp --prefix 460200 --name sanya
```

## 6. 校验清单（每次必做）

- [ ] 单元数一致（无缺失/多余）
- [ ] **名单外对称差 = 0**（用 `symmetric_difference().area`，不要用 `==`/`.equals`）
- [ ] 两两重叠 = 0；与邻县重叠 = 0
- [ ] 几何全部有效（`invalid = 0`）
- [ ] `domain_missing` / `domain_excess` 接近 0（残余报告可解释）
- [ ] `interior_rings` 数量合理（**警惕缝隙被"修复"成孔洞**）
- [ ] 面积变化表 vs 参考层
- [ ] 输出 overlay / side-by-side 预览图人工核对

## 7. 决策树：手绘图粗糙时怎么选

```
手绘图是否"在现行 SHP 上改"（有彩色块/明确改动区）？
├─ 是 → 方案 A（集合差切分，零缝隙）★ 首选
│        town/wenchang/reverse_by_color.py
└─ 否（完全重绘）
     ├─ 先方案 B 生成初版（EDT 唯一归属，无空隙）
     └─ 再 fix_slivers --mode snap-ref 配准修复（消叠、贴合、保真）

已有粗结果、只想补缝？
└─ fix_slivers --mode snap-ref --conflate-tol 90 --dissolve-by 乡镇码
```

**一句话**：缝隙是"逐区域独立取面"的必然产物；解法是**先分区后切分**
（方案A），或**全域唯一归属**（方案B），再叠加 **snap-ref 配准 + 争议区回退链 + 微孔洞清理**。
