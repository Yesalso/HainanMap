二、反向映射的几何基准（正逆变换公式）
====================================================================
反向映射完全复用"正向制图"的坐标配准参数，保证像素坐标与地理坐标一一对应。

source: Sanya/reverse_sanya_2002.py:44-45,53-59
  W, H = 3023, 1724
  TARGET_CRS = "EPSG:32649"
  minx,miny,maxx,maxy = sanya.total_bounds      # 三亚 SHP 要素外接矩形
  step_x = geo_w / W ,  step_y = geo_h / H      # 约 30 m/像素
  像素(i,j) -> 地理(x,y)：
      x = minx + (i + 0.5) * step_x
      y = maxy - (j + 0.5) * step_y
  (0.5 是像素中心偏移；j 轴为图像行，y 反向，即图片上 y 增大的方向对应北。)

source: Sanya/reconstruct_sanya_2002_16.py:32-34
  图幅四至硬编码为  MINX,MINY,MAXX,MAXY =
      283460.445, 2008356.577, 374161.780, 2060084.642
  （与同一 3023x1724 画布、30m/px 一致）
  该脚本 px2geo 用无 0.5 偏移的格点版本，随后对轮廓 buffer(0.5*STEP)
  扩半像素到真实像素边界，使相邻区域 "共用同一条界线上"（见其三）。

三、反向映射三道工序详解
====================================================================
3.1  初版（town/Sanya2002ToShp.py，理解"原理"用）
------------------------------------------------------------
- 读手绘图 town/Sanya_2002.png，取"最大连通域"作为边界线网（剔除文字）。
        Sanya2002ToShp.py:113-120  connectedComponents 找最大连通域
- 海岸线不用手绘图，而把原 SHP 三亚外部陆地边界栅格化进来：
        coast = rasterize_rings(outer,...)   net = max(img_lines, coast)
        (第138-139行) —— 手绘图只提供"内部乡镇界线"，外轮廓以 SHP 为权威。
- 形态学闭运算(cv2.MORPH_CLOSE, 3x3, 迭代2)桥接手绘断线(第141行)。
- 白色区域 8 连通洪泛 -> 陆地大区域(与陆地重合>50% 且质心在主岛内)为种子，
  按 REF_BY_CENTROID 的质心表匹配 2002 年 16 乡镇名(第164-192行)。
- 关键：所有"未归属"陆地像素（线网像素/细缝/碎块/离岛）用距离变换
  distanceTransform 按最近种子分配，实现"无缝、无重叠、全部陆地恰好唯一归属"
        (第194-210行)。
- 矢量化为每个区域 mask 找外轮廓，p.buffer(0.5*STEP) 向外扩半像素，
        相邻区域各自轮廓恰好落在同一条像素边界上(第212-230行)。
- 以 SHP 陆地为权威填充海岸细缝(SNAP_M=60m)，再按面积大者优先去重叠(第243-268行)。
- 输出 town/三亚2002.shp（Albers 与源一致），并替换进全岛 Hainan_town.shp(第313-331行)。

3.2  v3 洪泛区域法（Sanya/reverse_sanya_2002.py，本文核心）
------------------------------------------------------------
核心思想：两幅图（2002 底图、2007 底图）文字标注完全相同，可互相借用
"文字掩膜"把文字剔除，剩下来的黑色像素就是纯界线。

步骤（与文件头注释 reverse_sanya_2002.py:2-14 一致）：
  ① 文字掩膜 = 2007 黑像素 - 原 SHP 边界栅格（文字两图相同，故能用于 2002）
        dark2007 = (gray==0)；shp_lines 需逐乡镇栅格化（union().boundary 会
        抵消内部共享边界！注释在 :91）；
        text_mask = dark2007 & ~shp_lines          (:96-98)
  ② 2002 线网 = 2002 黑像素 - 文字掩膜           (:101)
        lines2002 = dark2002 & ~text_mask
        （同时 max(lines2002, shp_lines) 兜底，防止擦到海岸线 :106）
  ③ 形态学闭合(3x3, 2次)+膨胀1px，消除手绘断点与对角透缝(:108-116)
  ④ 白色区域 4/8 连通洪泛，得到各行政单元内部(:113-119)
        cv2.connectedComponentsWithStats(white, connectivity=8)
  ⑤ 每个白色区域取外轮廓 (RETR_EXTERNAL)，轮廓顶点吸附到最近线网像素
        (半径<=2px，即"吸附到线中心"，消除半像素偏移) (:129-149)
        ring -> Polygon -> buffer(0) 后得到像素环地理多边形
  ⑥ 与三亚外部陆地 outer 求交，只保留主体在陆地内的区域，
        离岸大块/海水区按面积分数排除 (:160-173)
  ⑦ 缝隙填充：以 SHP 陆地为权威，missing = outer - covered，
        每个缺口 buffer(40m) 求最大重叠邻居并入 (:175-205)
       剩余 = SHP 中真实小海岛，直接补回输出。
  ⑧ 属性继承：用"面积重叠最大"匹配到 2007 乡镇码，
       再经 TOWN_NAMES 字典映射为 2002/2007 名称 (:211-222)
       字段：OBJECTID / 乡镇码 / 乡镇名 / 面积km2
  ⑨ 输出 三亚乡镇2002_123.{shp,geojson, _Albers.shp}（转回源坐标 prj）(:224-235)
  ⑩ 校验：把结果多边形再栅格化，与 2002 线网做距离变换，统计重合率(:237-258)

  ★ 这就是"手绘图上的线如何变回地理多边形"的完整回答：
    像素坐标经 px2geo 线性变换 -> 米制坐标；外轮廓用原 SHP 权威；
    内部手绘线经"洪泛+轮廓+顶点吸附"转成矢量边界。

3.3  2002 年 16 乡镇重构（Sanya/reconstruct_sanya_2002_16.py）
------------------------------------------------------------
仅在 3.2 基础上按 2002 年行政区划命名（梅山/保港/崖城/雅亮/育才/高峰/天涯/
羊栏/荔枝沟/藤桥/林旺/田独/红沙/河东区/河西区/南海街道），方法几乎一致：
  - 4-连通洪泛 -> 白色区域(:85-86)；网格边界连通域视为海域排除(:87)
  - 按面积/质心 + NAME_BY_CENTROID 匹配名称；河东+南海连成一片的大区域
    用两个种子点(SPLIT_SEED_HE/NH)做"到种子距离更近者"切分(:206-212)
  - 线网/细缝像素按最近距离(MAXGAP_PX=10px)分配给乡镇(:227-237)
  - 离岛按 representative_point 最近邻并入(:253-264)
  - 相邻共用一条线：mask_to_geo 每区域轮廓 buffer(0.5*STEP)(:179-197)

====================================================================
四、修改的实现：fix_slivers.py（把逆向结果打磨成合法 SHP）
====================================================================
手绘/栅格矢量化必然带来三害：双线+细缝(Sliver Gap)、碎屑小部件、边界错位
(叠加显示"线不重合")。fix_slivers.py 用两种模式解决：
  模式 topo      ：仅靠图层自身拓扑自洽修复。
  模式 snap-ref  ：外挂"权威参考层"（海南村界.shp）做配准式修复（推荐）。

4.1 三步核心算法
  (1) 形态学编辑保真配准 conflate_to_reference (:889-930)
      对每个要素 A 与其权威参考 R_A：
        A_new = R_A  ∪  opening( A \ R_A , r )  \  opening( R_A \ A , r )
      解释：A 比参考多出来的部分(A\R_A)若"厚度 < 2r"判为 1px 配准噪声，
      用开运算 opening 抹平；若"厚度 > 2r"判为真实人工改动，予以保留。
      这恰好回答了"如何在不丢手绘改动的前提下消除叠加错位"。
      force=True 时 A_new = R_A，几何全用权威（会丢改动，故默认 preserve）。
      三亚选用 conflate_tol=90m，即 r=45m（约 1.5 像素），
      run.log 显示 9/9 要素配准成功，平均抹平 93.7 万 m²/要素的噪声。

  (2) 分区归一 resolve_partition (:624-816)
      配准后 A' 之间同时出现"重叠"（两边都说归自己）与"空洞"（原图层有、
      现在无人认领）。裁定采用归属回退链：
        原始图层归属 orig-owner -> 参考层归属 ref-owner
        -> 最长公共边界 longest-border -> 放弃并报告
      最后统一：每个要素 并上判给自己的碎片、减去判给别人的碎片、
      与权威域 domain 求交、repair_validity 兜底，达到"精确分区"。
      run.log 中共 30 个细小间隙全部按 orig-owner 归属（惯用 460200002 田独）。

  (3) 邻居顶点吸附 snap_neighbors (:823-882，topo 模式用)
      相距 < tol 的边界顶点互相吸附（参考线先按 tol/2 加密），实现共享边界
      严格重合；附带三重守卫（合法性/面积变化率/部件数增幅）避免吸附炸面。
      snap-ref 模式中默认跳过（配准已把边界贴到权威骨架上）。

4.2 完整流程与成效（run.log，2026-09-19 21:10 实测）
  命令：
    python fix_slivers.py --input 三亚乡镇2002_123.shp \
        --ref ../../海南村界.shp --ref-key 乡镇码 --key 乡镇码 \
        --mode snap-ref --conflate-tol 90 --dissolve-by 乡镇码

        (54 -> 9 要素) -> 形态学配准(9/9) -> 分区归一(30 个细小间隙全部分配)

  面积变化：各 2007 乡镇码 修复前后与参考层偏差多在百分之零点几以内，
        fwd 说明"手绘修改"确实保留、而"配准噪声"(<90m 厚)被抹平。

  校验关键指标（QA 报告）：

        sum_minus_union: 1.93 m2（几乎无重叠）

====================================================================
六、要点/坑位总结
====================================================================
1. 外轮廓权威原则：手绘图只提供"内部乡镇界线"，海岸线/市界永远以
   原 SHP(海南村界.shp 三亚部分)为准，用手绘外框只会带来不可控的偏斜。
2. 文字必须剔除：两幅底图文字相同，用"2007 黑像素 - SHP 边界栅格"
   一次性剥出文字掩膜；SHP 边界必须逐乡镇栅格化，不能先 union 再取 boundary
   （会抵消内部共享边）。
3. 无缝三件套：洪泛区域 -> 线网像素按最近距离分配 -> 轮廓 buffer(0.5*STEP)
   让相邻区域共线同界，杜绝"双线+黑缝"。
4. 手绘与现状的差异要分成两类：<2r 厚的是"配准噪声"应抹平，>2r 的是
   "真实手绘修改"必须保留——由形态学开运算的厚度阈值(r)精确划分。
5. 争议区归属必须以"原始图层(手绘语义)"为先，否则真实改动会在修复中丢失。
6. 迭代吸附/重复 buffer 容易把上万顶点要素拖死甚至炸面：snap-ref 模式
   跳过邻居吸附；边界 buffer 提前预计算；STRtree 做候选裁剪（见 assign_gaps）。
