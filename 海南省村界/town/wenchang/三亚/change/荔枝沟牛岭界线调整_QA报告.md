## 4. 方法（文昌经验沿用）

1. 配准式反向映射（正向制图参数像素↔米一一对应）；
2. 列平均提取笔画中心线 → simplify(10 m) + Chaikin×2（端点固定，贴线中心）；
3. 两端沿弧线方向延长至 U2 外边界精确闭合 → polygonize([U2边界, D]) 切成两面；
4. 以「牛岭主体重叠」判据归属两侧 → 严格分区 → 仅替换 SHP 中两行几何（变换回源
   CRS），其余 319 要素数值不动；
5. QA 报告 + overlay / sidebyside 出图。
