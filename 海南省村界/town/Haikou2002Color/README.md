# 海口 2002 乡镇图层更新说明（README）

本文档说明如何依据 2002 年手绘海口乡镇图，把 9 个乡镇/乡（新海乡、薛样乡、美安镇、
东营镇、桂林洋镇、演海镇、美仁坡乡、新民乡、谭文镇）更新进海口乡镇图层。

---

## 1. 目标与规则

- 在现有海口乡镇边界内**新增** 9 个乡镇：
  - 父级乡镇按新增线切开，面积相应减少；
  - **新增界线若接近/非常接近父级界线，则采用父级界线**（不产生"母乡镇细条/缝隙"）。
- **例外**：新海乡（连同西秀镇、长流镇）按图整体重切。
- **海岸线、县市界、乡镇间原有界线一律不改动**。

## 3. 配准

- 比例尺 **30 m/像素**；网格 **2036 × 2097**；图纸偏移 **(0, 310)**。
- 像素中心约定：`col=(x-minx)/sx-0.5`，`row=(maxy-y)/sy-0.5`。
- 用 `align.py` 复核：最优偏移仍为 `(0,310)`；且海口**多数乡镇的 base 边界与图上黑线 100% 重合**
  （石山、城西、龙泉、云龙、甲子…），说明配准可靠。

## 4. 处理流程（`build_haikou2002.py`）

1. **读 base**：`Hainan2002/Hainan_town.shp` 的海口 41 个单元（EPSG:32649 下运算）。
2. **色块类别栅格** `cls`：对 `Haikou_2002_a.png` 按 9 色（容差 20）分类，得到每像素颜色类别。
3. **黑线连通域** `cells`：对 `Haikou_2002.png` 的非黑像素做连通域标记（图上每个乡镇/岛屿一块）。
4. **西部块重切**：在 `西秀镇 ∪ 长流镇` 内，按连通域重切为 `新海乡 / 长流镇 / 西秀镇`
   （新海乡 = 颜色为新海乡的连通域；其余按与现状重叠归 长流/西秀；缝隙像素按最近单元补齐）。
5. **其余 8 个新乡镇**：`新乡镇 = 色块区域 ∩ 父级`。
6. **矢量化**：只取"涉及新单元"的格点边 → 追踪弧段 → 平滑 → `polygonize`，相邻单元共用同一条线。
7. **吸附（关键）**：色块边缘比黑线内缩约半个线宽，且手绘/配准存在窄差异。
   故把新乡镇整体外扩 `90 m` 后与父级求交并入：
   `新乡镇 = 新乡镇 ∪ (父级 ∩ 新乡镇.buffer(90m))`，
   使新界线落到黑线/父级界线中心，消除母乡镇细条（如灵山–桂林洋之间的演丰镇细条）。
8. **组装**：父级 `= 原几何 − 新乡镇`；追加 9 个新单元（CODE = `HK01`…`HK09`）。
9. **清理退化碎屑**：新增/重画单元中 `< 0.001 km²` 的孤立小块并入最近单元
   （仅处理 `HKxx` 单元，**不改动原乡镇**；演海镇的岛屿 > 0.001 km² 予以保留）。
10. **校验**（见 §6）后写回。

> 核心经验来自 `town/2002海口转换总结.txt`：手绘图映射必然有误差，**窄于容差的差异一律
> 并入新单元、保留 base 顺滑线**，即可消除"双线/细缝"。

## 6. 质量校验（当前结果）

- 单元数：全岛 **247** = 海口 **50**（原 41 + 新 9）+ 其他 197
- `内部重叠 = 0`、`无效几何 = 0`、`与原海口轮廓对称差 = 0`、`与邻县重叠 = 0`
- 与黑线贴合：多数 **97–100% ≤ 1px(30m)**；演海镇 93.9%≤1px / 99.5%≤2px
- 母乡镇细条（<60m）由约 0.9 km² 降至约 0.14 km²
- 仍存在的 3 处 <40m 间隔（石山-城西、金宇-海府、博爱-海甸）在 **base 数据本身**即存在，未改动

## 7. 备选方案（村界归并）

`build_haikou2002_village.py` 按"原始画法"把落在色块内的**整村**并入新乡镇，
新界线即村界（与 base 严丝合缝、绝无缝隙）。但手绘色块与村界并非一一对应，
细长乡镇（如东营镇）会明显偏离手绘图（IoU 仅约 0.4），故最终采用 §4 的
"色块区域 + 吸附父级界线"方案。
