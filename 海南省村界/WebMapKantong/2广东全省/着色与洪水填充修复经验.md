# 分级设色地图：配色与洪水填充修复经验

> 适用脚本：`SouthChina_town_county_1px_labeled_county.py`
> 输出：`华南乡镇界线_无标注_分层界线.png`（10000×6968，1px 界线，无注记）
> 数据：`2广东全省/华南乡镇界线.shp`（广东、广西、海南、港澳；投影 Albers，单位米）

---

## 一、背景

该脚本用「地级市分组 → 每市一种柔和色 → 1px 线网作堤坝做 4-连通油漆桶填色」生成纯色块地图。
实际运行后出现三类问题：

1. 北海与湛江**几乎同色**；
2. 密集边界处出现**跨城市串色**（一个城市被刷成邻居颜色）；
3. 密集城市/密集线网区域仍有**白色麻点**和**边界彩色毛边**。

下面按「现象 → 根因 → 修复 → 验证」记录。

---

## 二、问题一：相邻城市配成近色

### 现象

北海 `(151,174,230)`、湛江 `(171,171,237)`，色相仅差 0.048，ΔE≈21，肉眼几乎同色。

### 根因

1. 旧调色板用黄金角散布色相：`h = (i*0.6180339887) % 1`。
   58 个城市必然存在色相非常接近的配色对（北海取到 0.618、湛江取到 0.666）。
2. “相邻取色差最大”只对**已判定为相邻**的城市生效；而邻接判定用
   `boundary.intersection(boundary).length > 100`。
   北海与湛江的多边形是**重叠**关系（距离=0、交线长=0），于是从未被判为相邻，
   也就从未被要求取不同色。

### 修复

1. **调色板改为 CIE Lab 最远点采样**：在柔和色候选网格中，每次选离已选颜色最远的颜色，
   使任意两色感知色差尽量大。
2. **邻接判定改为几何距离**：`gi.distance(gj) <= 100m`，同时覆盖
   - 共享边界（距离 0）
   - 多边形重叠（距离 0）
   - 跨省接缝几十米的错位（距离 ≤ 100m）
3. **配色改为“贪心初值 + 局部搜索”**：目标函数
   `(最小相邻 ΔE, 相邻 ΔE 总和)`，随机交换两城颜色逐步改进。
4. 调色板大小使用实际单元数 `len(keys)`，避免与 `city_list` 数量不一致导致复用颜色。

### 关键代码位置

- `make_palette` / `_lab_of`：Lab 空间最远点采样
- `ADJ_TOL_M = 100.0`：邻接容差
- `_score` / `_assign_colors` / `_optimize_colors`：配色优化

### 验证

- 相邻最小感知色差 `ΔE≈46`；
- 同色冲突 0；
- 北海青绿 `(163,209,194)`、湛江粉 `(240,139,181)`，ΔE≈63。

## 三、问题二：洪水填充跨城市串色

### 现象

一个 4-连通区块里同时存在多座城市的几何填色，取主色后少数城市被整块覆盖。
插桩统计（原始代码）：

```
跨城市泄漏区块 = 217
被主色覆盖的错色像素 = 24158
例如 南宁 13218px + 崇左 16822px 被并成一块
     北海 12531px + 钦州 10053px 被并成一块
```

### 根因

- 1px 线网是 **8-连通**的，本身能分隔 4-连通区域；
- 但相邻城市的多边形各自 `simplify(40m)` / 迴針清理后，共享边不再完全重合，
  线网出现 **1px 断缝**；
- 4-连通油漆桶从断缝漏过去，把两座城市并成一个区块，`argmax` 取主色后另一城被覆盖。
- 原自检 `_bad_regions` 是在**重上色之后**统计的，重上色后每个区块天然只有一种颜色，
  所以该指标**恒为 0**，无法发现问题。

### 修复

1. **膨胀焊缝**：对线网做 `3×3` 膨胀，把 ≤2px 的断缝焊死；从 1 次膨胀开始自适应加大，
   直到“跨城市漏色区块 = 0”。
2. **自检前移**：在**重上色之前**统计每个区块包含的几何城市种类；
   多于一种即判为漏色，并统计会被覆盖的错色像素数。

### 关键代码位置

- `_region_mode(wall)`：区块划分 + 主色 + 漏色统计
- `for _dil in range(1, 5): ...`：自适应膨胀

### 验证

```
4-连通区块 5333（堤坝膨胀 2 次）
跨城市漏色区块 0
错色像素 0
```

## 四、问题三：密集区白点与彩色毛边

这是“漏色=0”之后仍能看到的两类残留，需要分别处理。

### 4.1 白色麻点

**现象**：被黑线围住的 1px 白点，集中在密集线网交汇处。

**根因**：相邻多边形各自 simplify 后，接缝处留有未覆盖的 `fill_idx==0` 小洞；
被线网围住后保持白色。

**修复（两道）**：

1. **接缝空洞填充**：`binary_fill_holes(fill_idx>0)` 找出被陆地包围的洞，
   只处理面积 `≤200px` 的封闭小洞，用邻域最大城市号（迭代 `grey_dilation`）填充；
   大洞/湖泊保留。
2. **封闭白点回填**：在最终图上对“未接触图像边界、面积 `≤200px` 的白色连通块”，
   用其邻域出现最多的城市色回填。

**关键代码位置**

- `接缝空洞填充`（rasterize 之后）
- `封闭白点回填`（自检 B 之后）
- `接缝空洞填充` 本次约 10887 px，`封闭白点回填` 约 4261 px

### 4.2 边界彩色毛边

**现象**：一个城市的颜色以 1px 宽的条带越到黑线另一侧，或两色直接贴在一起。

**根因**：膨胀环（堤坝）内、但不在 1px 黑线上的像素，用原始 `fill_idx` 几何色补色。
当两个城市多边形重叠/错位时，环上像素可能属于邻市，于是颜色越线。

**修复：分界补黑**

扫描最终图，找出所有“两种不同城市色直接 4-相邻”的位置，在膨胀环一侧补 1px 黑线：

```python
# 只比较非黑、非白、且颜色不同的 4-邻居
def _color_pair(a, b):
    return (a != b) & (a != 0) & (b != 0) & (a != 0xFFFFFF) & (b != 0xFFFFFF)

_h = _color_pair(P[:, :-1], P[:, 1:])   # 水平
_v = _color_pair(P[:-1, :], P[1:, :])   # 垂直
# 优先把“膨胀环上”的一侧压黑，尽量贴住原线
```

保证：**任意两种城市色之间必有黑线**。

**关键代码位置**：`分界补黑`

## 五、关键指标与自检方法

修复过程中新增/使用的客观指标（建议保留）：

| 指标 | 含义 | 期望 |
|---|---|---|
| 相邻最小 ΔE | 相邻城市配色差异 | 越大越易分辨 |
| 跨城市漏色区块 | 一个 4-连通区块含多种几何城市 | 0 |
| 错色像素 | 会被主色覆盖的少数派像素 | 0 |
| 两色直接 4-相邻 | 两种城市色之间没有黑线 | 0 |
| 封闭白点（≤200px） | 城市内部的白色麻点 | ≈0 |
| 非允许色像素 | 出现调色板之外的颜色 | 0 |

### 通用经验

- **自检必须在变换之前做**。在“已重上色”的数据上检查“是否单色”，结果必然为 0。
- 用**像素级可量化指标**（4-相邻对数、连通块颜色种类）代替肉眼判断。
- 对同一现象要看**放大 6 倍的最近邻裁剪图**，1px 问题在缩略图上不可见。

## 六、踩坑记录

### 6.1 反复 `thin(dilate(...))` 会侵蚀线网

尝试用「膨胀 → thin 细化」把线网变成“无断缝的 1px 堤坝”，但多次迭代后：

```
黑像素 780780 → 660927
区块 1 吞并几乎所有城市，漏色区块 1120，错色像素 97034
```

原因：`thin` 对膨胀结果不是幂等的，反复操作会缩短/丢失密集区的线。
**结论：补缝用膨胀即可，不要把膨胀结果再 thin 回去；膨胀环用“分界补黑”收尾。**

### 6.2 最近区块着色不一定更好

`cv2.distanceTransformWithLabels(DIST_LABEL_CCOMP)` 能把膨胀环分给“最近区块”，
但两个区块的分界不一定恰好落在 1px 黑线上，实测“两色直接 4-相邻”反而从 4417 增至 7536。
**结论：分界处必须有黑线，而不是靠重新分配颜色。**

### 6.3 几何色补环 + 补黑，比追求“完美着色”更稳

膨胀环用几何 `fill_idx` 补色，允许少量越线残影，
再统一用“分界补黑”把残影压成黑线，实现简单且可量化验证。

### 6.4 数据层面的坑

- 北海要素的 `省` 字段被标成 **广东省**（键为 `广东省|北海市`），与广西城市代码混用。
- 北海与湛江的多边形存在**重叠**（200m 内约 622 万 m²），不是干净共边。
- 广西部分城市的 `市` 字段是行政区代码（4501…），部分已转成名称，需映射统一。
  这些是上游合并脚本的数据问题，配色脚本只能“容错”，无法根治。

### 6.5 缩略图会放大“脏”的观感

预览图是 2400px 的 LANCZOS 缩放，10000px 原图中的 1px 线/色块在密集区会被插值混色。
**看细节必须看全分辨率 PNG，不要用缩略图判断 1px 问题。**

## 八、后续可选优化

1. 若要求“严格 1px”，可把「分界补黑」改为「把分界像素并入邻近区块颜色」，
   代价是极少量边界偏移 1px，但不会再出现 2×2 黑点。
2. 在数据源修复北海/钦州/防城港的 `省` 归属，并处理北海—湛江多边形重叠。
3. 如需在极大画布上进一步省内存，可将 `_region_mode` 的 key 继续用 int32 并分块计算。
